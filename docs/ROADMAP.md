# NovaTerm roadmap

## Milestone 0.1 — Android foundation
- [x] Kotlin + Jetpack Compose application shell
- [x] Dark hybrid interface
- [x] App-local command execution via Android system shell
- [x] Persistent working-directory handling for cd
- [x] Private workspace file browser
- [x] GitHub Actions debug APK artifact

## Milestone 0.2 — Terminal foundations
- [ ] Native PTY session with interactive full-screen applications
- [ ] Multiple terminal sessions and tabs
- [ ] Scrollback, selection, copy/paste and keyboard shortcuts
- [ ] User-configurable font size and color themes

## Milestone 0.3 — Linux userspace
- [ ] Verified proot and helper binaries for supported ABIs
- [ ] Downloadable Debian root filesystem with checksum verification
- [ ] First-run installation, pause/resume and repair
- [ ] Rootless mount, HOME and environment configuration
- [ ] Debian package manager integration (apt)

## Milestone 0.4 — Developer tools
- [ ] Python and pip
- [ ] Git and SSH client
- [ ] Compiler/toolchain packages
- [ ] Export/import of environment backups

## Milestone 0.5 — Multi-distro
- [ ] Ubuntu image
- [ ] User-managed distro profiles
- [ ] Storage access through Android Storage Access Framework
- [ ] Resource usage and process controls

Items not checked are plans, not existing features.
